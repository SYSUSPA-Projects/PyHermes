Learning path and examples
==========================

The public ``examples/`` directory is the executable half of the
documentation. It is tracked by Git and is intended to remain readable,
compact, and useful outside the development test suite.

Recommended order
-----------------

1. ``quick_start.ipynb`` shows one field projection and one low-level 2PCF.
2. ``sfc_projection.ipynb`` explains readers, weights, normalisation, and
   reusable ``SFCField`` products.
3. ``window.ipynb`` introduces field arithmetic, built-in kernels, custom
   windows, and projected-kernel composition.
4. ``counting.ipynb`` samples smoothed fields and constructs one-point PDFs.
5. ``corr2pcf.ipynb`` covers isotropic and anisotropic 2PCFs.
6. ``corr3pcf.ipynb`` covers standard 3PCFs and multipoles.
7. ``weighted_fields.ipynb`` builds velocity derivatives, potential, and
   acceleration from weighted fields and operator windows.

Three representations of one workflow
-------------------------------------

Most examples appear in three forms:

``examples/notebooks/``
   Explanatory, interactive tutorials with plotting code.

``examples/configs/``
   Minimal YAML descriptions of task inputs and outputs.

``examples/scripts/``
   Command-line drivers suitable for workstations or Slurm jobs.

For example, the same isotropic 2PCF can be launched as:

.. code-block:: bash

   cd examples
   python scripts/run_2pcf.py configs/param_2pcf.yaml

or from Python:

.. code-block:: python

   from pyhermes.param.parambase import read_param
   from pyhermes.theory.corr2pcf import Corr_2PCF

   params = read_param(config_path="./configs/param_2pcf.yaml")
   result = Corr_2PCF(params).run()

The YAML path values are relative to ``examples/``, so command-line examples
run from that directory. Each notebook changes to the same working directory
near the top.

Generated directories
---------------------

``examples/data/`` and ``examples/output/`` contain local data and products.
Only their ``.gitkeep`` files are tracked. Heavy correlation products are
generated by the scripts referenced in the corresponding notebooks.
