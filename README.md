### Method3 - from source
1. Download the source: git clone this repository,
   ```bash
   git clone https://github.com/PyHermes/PyHermes.git
   ```
2. Install: change your current workdir to PyHermes, then type
   ```bash
   cd PyHermes
   pip install .
   ```
3. Enjoy!
